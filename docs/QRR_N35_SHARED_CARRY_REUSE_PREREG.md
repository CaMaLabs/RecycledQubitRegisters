## New single algorithmic change: reversible carry ladder reused across ALL output bits of one public constant add

Reuse **exact prior** public modulo35 wrap/correct/uncompute, publicly shortened threshold comparators, old cached active/enable controls, coherent work/acc SWAP, and inverse modular multiplier. Swap only the `constant_add_from_prefix_carry` helper used by `optimized_modadd` for a NEW `constant_add_shared_carry`, with precisely the **same existing 6 clean carry qubits** and 9 clean Toffoli v-chain scratch. No additional data or auxiliary qubits (32 total), no oracle.

For `+k mod2^w`, w<=6, enabled by a clean Boolean public control `e`, compute each incoming carry `c[j+1]=e & ((old_x[j] & c[j]) if k_j==0 else (old_x[j] | c[j]))` with `c[0]=0`, into existing zeroed carry register, for j=0..w-2. Implement AND/OR of individual public constant bits with only explicit X, CX, CCX clean multi-control v-chains `primitive.multi_x`. The carry controls are gated by `e`, ensuring disabled addition is exact identity.

Then toggle output bits j from high to low: `new_x[j] = old_x[j] XOR (e & k_j) XOR c[j]`, reusing carry qubits directly with CNOTs. (No carry outside highest register bit required.) Carries are now entangled with new x; **correctly uncompute** the carry register from the UPDATED output via the subtract-k borrow identity `carry_into_j(old_x+k) = borrow_into_j(new_x-k)`. For j=w-2 downto0, with retained lower `borrow=c[j]`: `borrow_out=e & ((NOT new_x[j] & borrow) if k_j==0 else (NOT new_x[j] | borrow))`. XOR borrow_out into preexisting carry[j+1] (reverse-order uncompute), using X inversion of new_x[j] for negative controls, and restore new_x[j] after this temporary inversion. Every carry bit, v-chain scratch, flag and accumulator must return to zero. This is a single shared forward carry computation and backward borrow uncomputation, rather than recalculating per-output-bit public prefix comparators.

The formula is algebraically valid for all public 6-bit k, including k mod64=0 and k with set low bits; no true order used. The carry register is guaranteed clean on entry/exit by prior proven modular-add and wrap protocols, and the unchanged threshold predicate needs the same scratch/carry when called outside the add.
