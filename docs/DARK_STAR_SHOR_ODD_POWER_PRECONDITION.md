# Dark Star / PTP odd-power Shor preconditioning

Date: 2026-09-14

The exact kernel-constraint audit found one robust Shor-relevant consequence of the public residue structure: for semiprimes coprime to 3, `N mod 3 == 2` forces `3 | lambda(N)`. Across the 2,000-semiprime / 16,000-order validation set, this condition covered about 50.7% of cases with precision 1.0, and the observed probability that `3 | r` increased from about 60.94% overall to about 75.86% under the guarantee.

Larger wheel moduli (`2310`, `30030`) did not add analogous guaranteed divisors among `5,7,11,13`; their exact lambda-support signature space still reduced by only about 1.5x on average. This argues against treating larger PTP tables as a direct Shor-QPE shortcut.

## Exact odd-power identity

A stronger route follows from a standard group identity. If `a` has multiplicative order `r` modulo `N` and `L` is any positive integer, then

```text
ord_N(a^L) = r / gcd(r, L).
```

If `L` is odd, `d = gcd(r,L)` is odd, so order parity is preserved. When `r` is even, with `b = a^L mod N` and `r_b = r/d`,

```text
b^(r_b/2)
= a^(L r / (2d))
= (a^(r/2))^(L/d)
= a^(r/2) mod N,
```

because `L/d` is odd and `a^(r/2)` has order 2 inside the cyclic subgroup generated by `a`.

Therefore an odd-power transform preserves the standard Shor half-order witness and hence preserves the `gcd(x-1,N)` / `gcd(x+1,N)` factor-extraction outcome for that sampled base, while stripping any odd factors shared by `L` and `r` from the order-finding problem.

This does **not** automatically lower the textbook worst-case QPE width, which is normally chosen from a bound based on `N`. It can, however, reduce the actual order seen by an iterative/adaptive phase-estimation implementation, and it can simplify instance-generated modular-power circuits.

## N=35 implication

For the current benchmark,

```text
N = 35
seed base a = 2
N mod 3 = 2
```

so the public rule suggests cubing the base:

```text
b = 2^3 mod 35 = 8.
```

Validation-only orders are

```text
ord_35(2) = 12
ord_35(8) = 4.
```

The half-order witness is identical:

```text
2^6 mod 35 = 29
8^2 mod 35 = 29
```

and therefore the extracted factors remain `5` and `7`.

Crucially, the preconditioner does not need `r=12` to choose the exponent: it uses only the public condition `N mod 3 == 2`. The generic circuit constructor receives `N=35` and transformed base `8`; the true order is used only for validation/reporting.

## Interpretation boundary

This is not evidence of an asymptotic factoring breakthrough. Odd-power base transformation is an elementary order identity, and using products of small odd primes overlaps conceptually with classical Pollard `p-1` smoothness preprocessing. The research question here is narrower and hardware-oriented: whether combining public residue constraints, odd-power order stripping, and recycled/adaptive phase estimation measurably reduces the quantum order-finding burden without using the unknown factors or order in circuit construction.
