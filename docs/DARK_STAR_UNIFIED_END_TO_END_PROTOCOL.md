# Unified Dark Star / PTP / recycled Shor: frozen integration specification

**Research lead:** Chase Lunsford / CaMaLabs. **Date:** 2026-10-28. This is a *first end-to-end integration and regression-test harness*, not a new independently sampled quantum-advantage trial. All earlier PTP/QRR, N22–N25 positive and null results stay unchanged. GitHub Actions CPU only. **No quantum device or IBM Runtime submission.**

## Objective

Build **one executable full pipeline** from a synthetic semiprime to verified factors using *all compatible* original approaches: PTP 210 residue/root and 24/28 kernel-factor-pair constraints; LFK integer-coordinate factor search as a classical reference; safe (unpruned) prime/composite symmetry annotations; classical wheel-210 comparator; bounded residue-filtered Fermat midpoint searches (M=210-related odd wheels 105 and 15015) against ordinary Fermat baseline; publicly fixed gcd/power2, Pollard p−1 stage1 B31 and fixed 64-step rho/classical trial; public deterministic base selection; powers L in (1,3,5,7,105,1155,15015) plus **N%3==2 conditional cubic** as a separate fixed public policy; staged order-finding phase measurements and an online continued-fraction/direct modular/GCD verifier; optional one-phase recycled width and full wide register logical gate models; full classical and quantum source-count ledgers and zero-false-rejection PTP factor validation.

Not all methods give independent gains. LFK, full wheel-210 and classical trial are **full classical benchmark baselines** and are not falsely credited as additional QPU work avoided when running an explicitly labeled quantum counterfactual. Naive symmetry mirror canonicalization is **disabled**, because it can drop valid factor pairs for a fixed N. PTP-aware postprocessing currently validates actual factor residues *after* proper GCD recovery; it must not be claimed to eliminate order candidates before measuring. The public mod-3 odd-power rule is an experimental preconditioner, not a proven predictor. Larger odd powers are **ablation arms**; no best-of-seven secret-order selection.

## Boundary and complete path

1. User supplies a **small synthetic semiprime** via its p and q to the simulator harness. p/q are used only by a dedicated ideal eigenphase generator and final validation. The **public factoring/selection methods receive N and a only**. Do not present this as attacking unknown real customer/public keys.
2. Public-only preflight: PTP root/compatible kernel-pair count and mirror annotation; factor checks small wheel primes and public base ±1; bounded Fermat and PTP-allowed midpoint tests; bounded p−1, rho and trial. Exact factors are verified by p*q=N. If any succeed, full end-to-end factorization stops **classically**. To compare quantum methods anyway, run them explicitly labeled *counterfactual*: no practical quantum workload is claimed.
3. Independent classical benchmark controls: ordinary trial, optimized wheel-210, LFK-generated factor-pair method, vanilla Fermat, PTP-Fermat. They may solve N on their own; count tests and setup separately and never claim the model beats these baselines without real cost totals.
4. Precommitted public experimental arms: plain (L=1), unconditional L=3,5,7,105,1155,15015, and public conditional cubic (L=3 iff N%3==2, else L=1). Each arm computes b=pow(a,L,N) from public inputs only. Public gcd(b±1,N)/repeated-squaring guardrails are logged; any factor found is a **classical** result rather than quantum credit.
5. If a counterfactual simulated quantum arm is eligible, a *separate* ideal-QPE simulator computes r for its synthetic N solely from validation p/q and draws eigenphase s/r uniformly. At each public precision m=4,6,...,2bitlength(N) (with cap included), draw a discrete QPE output among up to 65 centered outcomes using the exact geometric-sum bin probabilities; omitted tail counted and **treated as an unmodeled unsuccessful measurement**, not silently resampled. Q<=65 uses all distinct outcome bins. This produces a **lower-bound / head-only simulation**, not full hardware distribution; no extra effective successes are credited to tail.
6. The public recovery routine gets only (N,b,y,m), evaluates ordinary CF denominators d with 1<d<=N, tests even d, modular equality b^d==1 and proper gcd(b^(d/2)±1,N), and then validates the discovered factors with the generated PTP factor pair (unless N has a wheel-prime factor). It never gets r or p/q. Record modular exponentiations, gcds and candidate denominator tests. Retry with higher public phase precision after unsuccessful measurements.
7. Count arithmetic CCX, CX, CSWAP using the repository's *source-level generic clean-MCX controlled-modmul gate construction* for each actual attempted (simulated) shot. Compare the same mathematical QPE outcomes for wide and recycled phase architectures in the **ideal model**. Wide peak = arithmetic width+max visited m; recycled peak=arithmetic width+1. These are logical modeled qubits (not real device physical qubits). Do not infer native routed circuit depth/fidelity.
8. Preserve complete root/selection/shot/gate, classical benchmark and final factor evidence for each synthetic case, all seven exponent arms including failures, and explicit four-way comparison of conventional plain wide/recycled vs PTP public conditional cube wide/recycled. Same fixed public inputs/seeds, one original population. A fully independent future test requires a fresh public-only sample frozen beforehand.

## Acceptance criteria

Tests must check exact factors for N=209 (3,11*19), N=713 (19,23*31), N=781 (29,11*71), N=35 (2,5*7), and at least one more pair; preserve PTP 48 roots / 24 or28 factor pairs; exact PTP factor-pair containment, no false rejections; direct CF never accesses hidden factors/order; head probability normalized and omitted tail bounded by approximately 1/63 for Q>65; odd-power order and half-order witness identity for validation; conditional cubic triggered exactly by public N mod3; source gate and width accounting; classical-stopped status vs explicitly counterfactual quantum results; zero QPU and no external service. Retain any failures with honest CI instead of silently dropping cases.

CPU-only bounded GitHub Actions can run the unit test and representative demo and preserve output JSON and README. No empirical advantage is claimed simply because the integrated code runs.
