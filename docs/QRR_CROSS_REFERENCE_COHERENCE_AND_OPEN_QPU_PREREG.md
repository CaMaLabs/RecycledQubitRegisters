## Spectral consensus pilot — clean independent synthetic model, not a factoring oracle

Primary goal: decide whether a circular-mean Fourier-phase coherence statistic can detect repeated synthetic order-linked structure **over permutation nulls** without mistaking nuisance/background signals for factoring evidence. Use precisely fixed public simulated QPE phase output distributions for toy orders r=4 and 6 and Q=256, generated with the project's full ideal-QPE FFT kernel; no hidden real QPU outcomes. 8 independent shot blocks of 2048 shots, 32 replicates per condition, deterministic SHA-seeded local RNG. Conditions: normal 0%, 15%, 35% uniform contamination and phase-scrambled null (same per-block histogram/bin values, randomly permuted between blocks). Use noise-only uniform cases as additional null. Statistic `C(k)=|mean_block fft_centered_block[k]/|fft_centered_block[k]||`, zero FFT bins contribute 0. At prespecified **k=r** and up to first 16 harmonics (k<=Q/2), compare same target harmonic against null distribution; no selecting k by strongest observed peak. Detection is above 95th percentile of null C(k) (with predeclared tie handling), and report empirical null false positives at fixed threshold, power and null-validation. False positive <=10% required under test null and power >=75% for 0% and 15% contamination; if those fail, method FAILS. Include clear failure on high-noise cases and no inference of factoring performance. The labels r are used ONLY to choose evaluation harmonic in this deliberate control study, not to select a secret quantum order.
