# Dark Star PTP public midpoint bounds: proof and reproducible counterexample audit

Research lead Chase Lunsford / CaMaLabs. Date 2026-10-30. This is a **mathematical audit** of whether existing PTP/Fermat small-prime quadratic residue masks can certify a useful upper bound on the unknown Fermat factor-pair midpoint. No quantum computing. No cryptographic keys.

### Precise claims to check, fixed before implementation

1. Let N=pq odd, 1<p≤q, and x=(p+q)/2 integer; the true nontrivial Fermat midpoint offset is D=x-ceil(sqrt N). If trial division or an external promise **certifies** p≥L>0, then since f(t)=(t+N/t)/2 decreases for t≤sqrt N, an exact integer upper bound is `x≤floor((L*L+N)/(2*L))`. If L is not certified public information, do NOT use it as a routing oracle. This is a generic classical factor-size bound, not a new PTP theorem.
2. Every odd N and every odd product M of sieving primes admit the trivial midpoint x_triv=(N+1)/2. For each integer k, `(x_triv+kM)^2-N ≡ ((N−1)/2)^2 (mod M)`; therefore every individual quadratic-residue mask passes that entire arithmetic progression. Necessary PTP QR residue tests alone cannot prove all future midpoint positions impossible, nor supply a factor-proximity guarantee. Some of those positions correspond to no actual divisor: distinguish passing a necessary local residue test from real square/factor recovery.
3. Concrete **constructed counterexample**, *not* a random prospective validation cohort: two 30-bit prime-pair semiprimes (N,p,q)=(922551607,29989,30763) and (537116557,8719,61603) have the same public `N%255255=60037`, but true D=2 and D=11985. Verify primality, exact products, exact D, same bitlength, same wheel-residue signatures and residue-test acceptance of actual midpoints. Therefore **bitlength and N modulo 255255 alone** cannot classify near versus far. This does NOT prove there is no better public-N predictor using different features or a general factorization algorithm.
4. Assess the conditional RSA balanced-prime promise p,q in [2^1023,2^1024): factor ratio≤2 implies `D/sqrt N ≤ 3/(2√2)−1 ≈0.06066017`, hence a worst-case 2048-bit search window of order 2^1020 midpoint coordinates. That is exponentially beyond our few-thousand-position demonstrations. This is a mathematical worst-case upper envelope subject to a **known balanced-factor promise**, NOT a certificate that an individual unknown N has midpoint near the start, and is NOT a security estimate for Shor's quantum algorithm.
5. The quantum RSA circuit resource and ML-KEM LWE geometry studies are separate; their abstract gate reductions cannot be multiplied blindly with classical QR filtering. Independently audit existing results with accurate scope (synthetic vs standardized, source vs compiled vs device).
6. Implement a deterministic, standard-library test/audit with machine JSON receipt and exact checks of the above. Run CPU-only via GitHub Actions; push original JSON/report and update `docs/RESEARCH_LOG.md`. Preserve previous N26–N34 benchmark results and failures unchanged. No thresholds tuned after fact, no performance or fresh-holdout claims for the constructed counterexample.
