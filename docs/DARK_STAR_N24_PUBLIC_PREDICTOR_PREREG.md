## Why: preserve the actual N22 and N23 records, not a favorable subgroup

The previous independently selected N22 8-row 22-bit full-outcome ideal QPE holdout had a preregistered 3/4 **N%3==2** conditional cube-model win, while a NEW 23-bit all-outcome study had that same trigger **0/4** wins and 2 factor-incapable cases, with the **N%3==1 control** containing 3/4 model wins and one factor-incapable. Both source reports are preserved. The 23-bit group inversion is *hypothesis generating*, not evidence to reverse the original trigger in that same set. Before any new outcome, freeze the inverted candidate `P1=(N%3==1)` against balanced equally sized `N%3==2` control. The separate N35 robust public sign-selector gate-cost result does not validate cubic order prediction; the same-circuit native hardware gate still FAILS.

**Independent algebraic invariant** for any gcd(a,N)=1 and b=a^3 modN: `ord(b)=r/gcd(r,3)` (standard group theory). Since `gcd(r,3)` is odd, ord(r) and ord(b) have the same parity; whenever even, `b^(ord(b)/2) == a^(r/2) mod N` (if gcd=1 then cube of an order-two element equals itself, if gcd=3 equality is immediate). Hence the STANDARD even-order half-power GCD proper-factor witness of a and b must match, regardless of order shortening. Record this **necessary** evidence separately from phase-estimation success probabilities, continued-fraction acceptance counts, compiled gates, or full QPE. No theorem novelty is asserted.
