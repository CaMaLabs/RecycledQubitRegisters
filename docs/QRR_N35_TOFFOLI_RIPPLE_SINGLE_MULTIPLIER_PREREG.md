# FROZEN: explicitly reversible X/CNOT/Toffoli modular multiplication single-round N35 feasibility

**2026-10-16 America/Los_Angeles. Research lead and design direction: Chase Lunsford / CaMaLabs.** This document is committed before the first native target compiler data. ZERO IBM/QPU runtime authorized for this study, and the new standalone script MUST NOT call Sampler or Estimator.

## Why this experiment and honest prior record

The real IBM Open Plan Fez N15 shor15 phase-recycled-vs-wide hardware result was successful on a *small* N15 modulus, but N15 base2 order4 is unchanged by cubing, so it does not test Dark Star odd-power order reduction. The N35 four-bit order-independent full-register permutation compiler showed ~61% CZ reduction under public base2→cube8 (true order12→4), but all four compiled arms failed earlier conservative free-device limits **800 native CZ, depth2000**. Subsequent general reversible n-bit shift-and-add using eagerly controlled Draper QFT adders (recycled CZ 1,732,072→859,632, wide CZ1,733,136→860,151) reduced resources internally but made absolute compilation dramatically worse. Original full source receipts, successful jobs and negative results stay immutable.

**New action:** isolate exactly ONE genuine public, unencoded, full-residue controlled modular multiplier `U_a: |c>|y>|0...0>→|c>|a^c y mod35>|0...0>`, with identity on invalid y>=35 and all ancillas clean, for a=2 (baseline), 8 (cube). No phase QPE rounds or Fourier/QFT algorithm in this pilot. Order12→4 is a validation LABEL only, *not used* to construct the circuit, and there is no 12-state orbit or precomputed private prime/order data. This isolates circuit kernel cost and semantic correctness, NOT a factor-recovering quantum device experiment.

## Frozen construction and independent exhaustive gate-basis validation

Use solely Qiskit primitive X, CNOT, CCX/Toffoli for the basis reversible kernel. Build public controlled modular addition by classical constant with a 6-bit target, external controls and CLEAN auxiliaries:

1. Evaluate carry recurrence of adding unsigned `2^6-threshold` to the target using six clean carry ancillas, `carry[i+1]=target[i]&carry[i]` if corresponding constant bit 0, and `carry[i+1]=target[i]|carry[i]` if bit1; compute and uncompute it around a target predicate. The output carry equals `target>=threshold` for threshold in (0,64). Gate implement OR as 2 CNOT + 1 CCX, AND as one CCX (with constant initialization c0=0). For predicate `x<k`, invert the carry condition in the reversible predicate toggle, keeping all carry ancillas zero on exit.
2. A public constant modulo2^6 addition is a sequence of descending-order controlled increments on target bit suffixes for each set k bit. For each increment, toggle upper bits from high to low by a multi-controlled X where all lower relevant target bits are still their previous values, then toggle least bit. Synthesize each multi-controlled X *explicitly* with a forward/reverse **clean Toffoli v-chain** (no annotated .control wrappers), in a separate scratch register. The chain returns every scratch bit to zero.
3. For `0<=target<35`, controlled modular constant `+k mod35`: compute wrap flag `x>=35-k`; controlled add k modulo64; if wrap flag add `-35 modulo64`; then uncompute wrap flag from output predicate `x<k`. All four branches must preserve identity when external controls off, and flags carry/scratch end zero.
4. Controlled multiplication in a clean accumulator: controlled modular additions of `a*2^i mod35` for every bit i of original 6-bit y, controlled work/accumulator SWAP, then subtract `(a^{-1}*2^i mod35)` of new work bits to clear accumulator. Guard on a clean public validity predicate `y<35`; any y>=35 and c=0 unchanged, all auxiliaries zero.
5. Classical binary exhaustive *actual Qiskit gate instruction interpreter* on BOTH a=2 and a=8, every y=0..63, c∈{0,1}, all ancillas initially zero: verify (a) target work exactly equals public multiplication, (b) control bit unchanged, (c) **EVERY** helper scratch/flag/accumulator bit zero, (d) only X/CX/CCX in primitive circuit. This is strictly stronger than a separate algebraic shadow helper selftest, though still doesn't prove noisy native hardware implementation.
6. If any semantic assertion fails, save the error receipt, fail the run; no resource optimization, QPE expansion or QPU experiment is warranted before fixing gate-level correctness.
