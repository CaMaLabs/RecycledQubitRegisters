# Research triage — XOR, borrowed/clean ancillae and reversible arithmetic for Shor (2025–Oct 2026)

**Research lead:** Chase Lunsford / CaMaLabs. **Reviewed:** 2026-10-30. This is a **literature search and concrete test proposal only**; NO new circuit built, simulated, benchmarked, QPU job run, or hardware advantage proved during this literature audit. Sources refer to preprints or peer-reviewed publications as marked. This work pertains to RSA/Shor reversible arithmetic **not** automatically ML-KEM cryptanalysis.

## Mathematical justification and limit

For classical/quantum binary bits, a coherent CNOT computes XOR into a target `|a,b,0> -> |a,b,a XOR b>`. This is a reversible linear function over `GF(2)`; it creates correlations/entanglement in general, **not a clone of an unknown quantum state**. Repeating XOR gates, X and swaps produces affine Boolean maps and **cannot by itself** implement a general integer adder or modular multiplier: nonlinear carry bits require Toffoli/AND-equivalent resources.

A useful exact carry decomposition is
`t=a XOR b`, `s=t XOR c`, `carry=(a AND b) XOR (c AND t)`.
CNOT computes t/s, two controlled-controlled-X (Toffoli) accumulate two AND products into a clean carry ancilla, and reverse CNOTs uncompute temporary t. Count **all** extra clean/dirty ancilla wires, CNOT, Toffoli/T, depth, physical routing, phase fidelity, and cleanup; this identity alone is NOT a demonstrable gate-count improvement over known adders. Alternative circuits can exploit shared XOR/parity terms across many carries, reduce high-control Toffolis or shorten serial carry depth. Temporary logical-AND and measurement-based uncomputation can replace expensive coherent AND cleanup where rigorous phase/feedforward conditions allow it.

## Specific CaMaLabs integration / existing evidence

The real existing N35 dynamic Qiskit arithmetic source is `hardware/qrr_n35_true_recycled_phase_feedforward.py`. Each public controlled modular multiplier uses six coherent work bits, a **six-bit accumulator**, **six-bit carry register**, wrap1, valid1, active1, enable1, plus one recycled phase qubit. It also declares scratch9, found PROVEN UNUSED in `docs/QRR_N35_TRUE_RECYCLED_IDLE_SCRATCH_RESULT.md`, reducing **32→23 source wires** when removed. However the *native Fez CZ/depth robustness gate failed*: do not claim reusing scratch accelerates the circuit without measuring genuine native resource changes. Original phase-exact source tests require all controls, all 64 possible work states (including y>=35 invalid-state identity), **+1 exact complex phase** and all arithmetic helpers returned clean. This non-obvious global-phase constraint is critical if optimizing with relative-phase Toffoli, borrowed dirty ancilla, or measurement uncomputation.

### Experimental A/B plan (NOT YET RUN)

**Source arms:**
- Control A0: original exact 23-active-source-wire N35 arithmetic, unchanged circuits, same known public multipliers.
- A1: share XOR/parity propagate terms using clean ancilla temporary carry, uncompute to |0>; rewrite only one `modadd` stage at a time.
- A2: reduce Toffoli/controls with Reed–Muller factoring and Gidney's 2-clean+(n−2)-dirty or 3-clean constant-adder templates; borrowed data must be restored coherently on arbitrary superpositions, including entanglement.
- A3: transplant the 2026 ancilla-free logarithmic-depth adder or comparator into *only* modular-wrap/addition subroutines; verify correctness before whole power QPE.
- Optional A4: measurement-based uncomputation **only after** complete conditional feedforward correctness and branch semantics have been proved; retain it as a separate hardware-feasibility track.

**Proof gates before compiler read:** for every N35 public controlled multiplier and both control 0/1, exhaustively test y=0..63 and verify `|c,y,0..> → |c,(c?u*y mod35:y),0..>` for valid y<35 and unchanged y>=35; enforce exact +1 phase (not merely basis-state permutation), all ancillas clean, plus coherent superposition interference/ideal QPE equivalence. Include dirty ancilla starting 0/1 and selected entangled clean-work source tests. No injected multiplicative order or secret factors. Do not measure coherent work or parity ancillas in a way that reveals uncomputed data.

**Full-cost metrics:** count native Fez CZ, depth, two-qubit path/SWAP, routing/locality, Toffoli, **T-count and T-depth in separately stated fault-tolerant decomposition**, CNOT, peak active logical qubits, reset/measure/classical feedforward, ideally multiple compiler seeds, before QPU. If a variant reduces abstract Toffoli at cost of more qubits and worse native CZ, preserve the loss. Test separately on small modular adders n=4,6,8, then genuine N35 controlled-U base2/base8 b4/6/8; later fresh held-out other semiprimes and sources, not just N35.

**Primary falsifiable goal suggestion:** exact source-state semantics and global phase pass for every public power; then candidate paired native CZ and native depth both strictly better than baseline in ≥3/4 fixed transpiler seeds for **each** required base/precision (and no unpriced increase in active qubits or false implied fault-tolerant improvement). If physical criteria fail, report source-only savings without misleading conclusion. No actual QPU or IBM Runtime unless separately authorized.

## Decision

**Yes**, XOR plus ancilla parity networks is a valid reversible-arithmetic *engineering* avenue, but XOR-only Clifford circuits are affine and do not evade nonlinear modular carries; improvement is in gate synthesis, depth, and resource tradeoffs, not a new shortcut that turns RSA-2048 factorization into an easy task. The highest-value experiment is a **correctness-first clean/dirty-ancilla and ancilla-free add/comparator shootout** inside the existing 6-bit controlled modular arithmetic, with actual compiler evidence and strong original baseline.
