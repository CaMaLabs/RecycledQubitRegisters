## Fixed one-variant algorithm and semantics

Use original public modulus N35 and base a=2 or cubic base 8, with identical *unchanged* cached phase/valid/per-input source-enable controls and exact original full-register reversible multiplier from `hardware/qrr_n35_latched_controls_single_modmul.py`; no known true multiplicative orders/orbits/private factors enter construction. Keep `reference.predicate`, `reference.multi_x`, `reference.controlled_swap` from the original X/CX/CCX Toffoli primitive source `hardware/qrr_n35_single_modmul_ripple_toffoli.py`. **Only** replace the modular constant adder and make threshold comparisons constant-specific. These are two coupled, explicitly frozen modifications of one new variant (no searching variants).

1. In a conditional `+k mod 2^w` (w=6, fixed public k), iterate output bit j DESCENDING, while all source bits i<j remain UNCHANGED. Toggle output bit j iff enabled AND (the public bit `k_j` XOR the carry into j). Carry into j for `j>0` is `input[j-1:0] >= 2^j - (k mod 2^j)` whenever `k mod 2^j !=0`. Implement this controlled predicate directly by the proven `reference.predicate` toggling output bit j; separately toggle output bit j if `k_j=1`, via the verified primitive `reference.multi_x` on the same external enable control. For j=0 carry is always zero. Do not introduce unclean persistent carry state. The comparator uses the unmodified smaller lower register, and returns its scratch to zero before any lower bit is changed.
2. Public-threshold shortcut: for `t` divisible by `2^s`, **unsigned** comparison `x>=t` and `x<t` are equivalent to `(x>>s)>=(t>>s)` and `(x>>s)<(t>>s)`. Thus skip low s bits of state and respective CLEAN carry workspace when evaluating either predicate, using the same original verified comparator. Applies to both modular-add wrap thresholds `N-k`, its output-uncompute threshold `k`, and bit-j incoming-carry thresholds. Only compute s from public t; no source-work bit pruning and no order/orbit knowledge.
3. Controlled modular addition on VALID x∈[0,34], with external `enable`, remains exactly: compute reversible wrap flag `x>=35-k`; conditionally add k modulo64 with new per-bit direct incoming-carry logic; conditionally add `-35 modulo64` if wrap flag; then uncompute wrap using `x<k` with shortcut. Same zeroed flag/carry/scratch contract. External enable0 must preserve ANY x in 0..63 as identity, and all helpers clean. All components remain *only X, CX, CCX*.
4. Build the complete ONE controlled multiplier of a=2 and a=8 with public y<35 validity, controlled forward accumulator additions, coherent 6-bit work/acc swap, inverse-weighted subtraction/uncomputation; zero all 25 auxiliaries (6 accumulator, wrap+valid, 6 carry, 9 scratch, active+enable) and leave phase unchanged. Exactly 32 application qubits. Do not hardcode answer based on a known order.
