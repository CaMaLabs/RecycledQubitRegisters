Research lead: Chase Lunsford / CaMaLabs. Date: 2026-10-29. **No IBM quantum jobs or paid/free Runtime.** This is a prospective CPU-only falsification of *end-to-end classical factoring latency*, not a new quantum advantage trial. ## Frozen router BEFORE sampling/label inspection

The candidate algorithm is a fixed publicly computable **classical method portfolio**, not an oracle predicting hidden p or q:
1. `gcd(N,210)` and direct small wheel primes 2,3,5,7; stop if proper factor.
2. Test **eight** successive exact Fermat midpoints `ceil(sqrt(N))+j`, j=0..7; every `isqrt` and comparison is counted.
3. Deterministic public **Brent batched-GCD Pollard rho** with two publicly fixed polynomial coefficients `c=1,3`, initial y=2 and 3, **maximum 384 modular squarings total**, maximum block size 16, no private order/factor oracle; keep every modular squaring, accumulated product, gcd, fallback gcd, and restart count in the ledger. Do NOT increase the rho budget after inspecting holdout results.
4. Optionally try **restored Dark Star QR midpoint sieve** with public wheel `M=255255` (odd primes 3,5,7,11,13,17) but ONLY if previous methods fail and public `(ceil(sqrt(N))^2 - N) <= ceil(sqrt(N))/4` (integer comparison). This public proximity heuristic is exploratory, not a theorem predicting close prime factors. The QR stage may scan at most 128 midpoint x coordinates from initial x and at most **8** exact integer roots, with explicit modular-membership, setup/elapsed, and stopping counts. Never reject a midpoint that can genuinely produce factors; never use discredited symmetric PTP pair canonicalization.
5. If still unresolved, **complete conventional wheel-210 trial division** as public, guaranteed-to-factor synthetic semiprime fallback; record all its divisibility tests and its full extra cost. There is NO hidden selection by true factors, validation-only orders, or simulated QPE scores. The winning method is the first actual valid factor, not whichever benchmark retrospectively ran fastest.
6. Independent benchmark arms **complete wheel210**, **complete PTP LFK kernel**, **previous expensive fixed preflight** (unchanged historical public filters with restored M255255), and **plain Fermat** limited to the same 4096 midpoint span; no result-specific changes. All arms run on identical public N with their total elapsed times. Eight or more independent repeats per arm on the same runner, **interleaved rotated method order** per repeat to reduce warmup/order bias; include per-N setup, preprocessing, failed methods, fallback, and verification, retain each raw timing (not just an average). The median within each N and the paired median/log-ratio across frozen N are descriptive noisy microbenchmarks, not physics or scalability proof.
7. Primary cost/speed gate preregistered: candidate router must beat BOTH complete standalone wheel210 and standalone PTP/LFK in median per-N measured elapsed time on **>=9 of 16** fresh cases, all factor recoveries correct, and unpriced setup omitted nowhere. Treat ties/losses honestly and DO NOT claim new asymptotic method or external-key factoring. Distinguish reduction in expensive `isqrt` calls from total elapsed time. Keep previous fixed-pipeline comparison separate and label classical improvements as *classical algorithm/engineering* only. If either baseline majority gate fails, PRIMARY FAIL.

## Independent new public cohort and freeze before testing

Construct synthetic two-distinct-prime semiprimes **exactly 28-bit** `2^27<=N<2^28`, prime frame **p >= 9500, q <= 28000, p<q**, gcd(N,210)=1. Factor-generating primes are for benchmark truth **only** and must not enter public rank/base/router. Rank all candidate public N by SHA256 salt `DARKSTAR-ROUTER-N28-PUBLIC-20261029|group|N` and select exactly **8 Nmod3=1** plus **8 Nmod3=2**. The public manifest includes only N, group, rank, Nmod210, the deterministic fixed policy name, SHA256 canonical row hash, and complete frame/group counts. ZERO prime factors, true multiplicative orders, filtering results, timing, or model score in manifest. Freeze manifest via successful separate GitHub Actions run and GitHub commit **before** scoring or validating any case. No resampling based on outcome.

## Validation and boundaries

- All 16 original cases, all 8 interleaved timing repeats, every branch and exact verified factor pair, standalone baselines, cumulative modular and division counts preserved; original per-case SHA and grouped summary.
- Unit tests for small primes, close and far factors, rho both success and failure, fixed cap, original discredited PTP symmetry never enabled, and QR necessary-congruence check. Test public-only router function signature excludes p/q. No IBM SDK imports.
- The 28-bit public sample is distinct from prior 26/27-bit samples. No model training or selected thresholds on new sample; thresholds declared above before freeze. An external blinded replication and larger integers would be needed for general conclusions.
- Report negative results and preserve all primary/secondary milestones into `docs/RESEARCH_LOG.md` before any further experiments. Zero real QPU usage, zero paid/free runtime.
