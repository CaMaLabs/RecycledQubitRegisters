# Quantum and Dark Star workflow audit — 2026-10-25

Research lead: Chase Lunsford / CaMaLabs. Audit AI-assisted.

## Keep the research lanes distinct

This repository contains phase-register recycling, native compiler/hardware feasibility and Dark Star/order-finding ideal-model experiments. CaMaLabs/Dark_Star is a separate small repository; do not infer that its README represents this repository's latest work. LWE_GeometryLab is a separate cryptanalytic experiment lineage.

## Preserve established milestones and limits

The true recycled N35 source reduced from 32 to23 logical qubits after proving nine scratch bits unused. Initial placement at physical site85 succeeds 12/12, but strict fixed-site routing fails all12; logical recycling does not prove fixed physical occupancy. Native CZ<=800/depth<=2000 feasibility gates still fail; do not submit N35 hardware jobs. Prior real N15 Open Plan hardware evidence remains a separate success.

The latest default-branch commits preserve the N25 online-verifier study. Its independently frozen eight-case public population yields zero bounded model wins, six inconclusive comparisons and two undefined per-success ratios. Seven of eight are solved by the limited classical-first budget. Source-level CCX modeling, ideal phases generated using validation-only orders, compiler-native resources and real QPU performance are separate fidelity levels. These results do not establish factoring advantage.

## Optimized loop

1. Freeze population, method, target snapshot, costs, controls and stopping rules before scoring. Repairs to software contracts must retain the failed attempt and amend the protocol before new scoring.
2. Write a compact local/CPU contract smoke test before large CI matrices: unique probability bins, serialization schema, merge shape, result count and numerical normalization. Recent N25 sampler/field/merge failures illustrate why this belongs before science sharding.
3. Preserve original science shards once. Archive/merge failures are repaired by downloading unchanged original artifacts; never rerun science to recover a publication error.
4. One scoring workflow and one preservation path per experiment are sufficient. Historical workflows remain reproducible, but do not accumulate a new one-off preservation workflow for every routine retry; a future reusable collector should validate manifest hash, source run SHA, exact expected shard set, checksums and schema before publishing.
5. Compare layouts against the same frozen backend target object/snapshot and matched compiler seeds. Archived unpinned baselines are not a controlled same-target intervention comparison.
6. For N25, reduce uncertainty and count online classical-verifier work under a preregistered budget before increasing integer size. For N35, arithmetic gate reduction and routing constraints are separate interventions.
7. Keep QPU authorization fail-closed: only existing free Open Plan scope, no paid runtime, and no submission while documented feasibility gates fail. A CPU target read is not a quantum execution.

This audit changes workflow policy only; it launches no QPU or new model-scoring job. It does not claim a reusable collector has already been implemented.
