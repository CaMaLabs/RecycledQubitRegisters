## One scope-expansion intervention, no new arithmetic or hidden order

Implement **four controls and shared work/scratch** in a new source script using **the exact same original or selected `modadd` constructors**. Source circuit: `phase[4], work[6], acc[6], wrap[1], valid[1], carry[6], scratch[9], active[1], enable[1]` = **35 logical qubits; exactly 25 clean ancillas**. Initialize valid by the original phase-correct public predicate `work<35`, and clean it once at the end. For each public phase bit j∈{0,1,2,3}, compute public multiplier `m_j = pow(a,2**j,35)` from exponentiation alone. If `m_j==1`, omit only that **provably identity** controlled multiplication, with no true period/order inspection. For nonidentity powers, latch `active = phase[j] AND valid` using the original exact CCX; 6 forward weighted clean-accumulator mod35 adds driven by exact clean source `enable = active AND work[i]`, work/acc controlled swaps, 6 inverse weighted clean-accumulator mod35 adds, uncompute both enable and active. Carry/scratch/wrap/acc must remain zero at all original module boundaries. Both source variants have identical layout and source semantic controls. No unmeasured four-round QFT or N35 factoring claim.

Both public bases **a=2 and a³=8**. Public 4-round powers must match `a2:[2,4,16,11]` and `cube8:[8,29,1,1]`; cube8 has exactly **two** public identity stages; a2 has zero. Never hardcode group multiplicative order or prime factors into the program; the expected outputs are verified from modular exponentiation by the four publicly selected control bits alone, not a precomputed orbit truth table. The prior exact single-stage original and selected sources MUST first be rebuilt and quantum-phase checked and 34 public k source-score rows compared **exactly to original archived receipts** (no selector retuning).
