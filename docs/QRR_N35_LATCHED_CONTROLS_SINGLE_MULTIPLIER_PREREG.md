## Exactly one new intervention: cache public Boolean enable controls

Keep **EXACT SAME** modular arithmetic and clean ancilla arithmetic primitives by importing `hardware/qrr_n35_single_modmul_ripple_toffoli.py` functions `predicate`, `modadd`, `controlled_swap` and `multi_x`. Do not rewrite comparator, mod-add carry or ripple algorithms; no hidden order, prime factors, 12-state orbit, circuit truth-table precomputation, or change to physical target. Instead compute `active = phase & valid` once after publicly testing `work < N`, then for each source-bit weighted modular add compute `enable = active & source_bit`, call the unchanged `modadd(..., controls=[enable])`, and uncompute `enable` immediately. Reuse `active` for the controlled work/acc swap and both forward/back weighted-add loops; uncompute active and validity before return. Add **two clean ancillas** (`active` and `enable`), so expected logical width 32 vs original 30. Worst-case control-fan-in is reduced for many operations; whether it saves native CZ is an empirical result, not guaranteed. Public, order-blind base choice `a=2` versus `a=8=2^3 mod 35`; neither factor nor true multiplicative order is read for constructing this circuit.

The experiment is **ONE** full-six-bit-residue (valid y<35 and invalid y>=35) controlled modular multiplier **PER public base**, no QPE, no Shor factoring claim. Exhaustively independently interpret the emitted **actual** primitive instruction stream (only X, CX, CCX) for ALL 64 work values ×2 control bits=**128 basis inputs per arm**, and independently assert exact public multiplier, same control, EVERY aux qubit (including the two new cached controls) zero, and identity when control0/invalid. Include coherent reversibility implication from this exact basis mapping, but no noisy-QPU proof.
