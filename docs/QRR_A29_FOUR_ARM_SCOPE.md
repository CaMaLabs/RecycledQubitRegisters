# A29 four-arm control — first checkpoint

Run `python3 hardware/qrr_a29_four_arm_residue_proxy.py` from the repository root. Uses Python standard library, no QPU. Arms are baseline binary, baseline Fourier, residue-filtered binary, residue-filtered Fourier. The experiment checks five public toy composites, identical small addition kernels and candidate-divisibility test counts. The residue-filtering control is a real public-only wheel based on coprimality modulo 210, but **not** the original Dark Star Fourier/NTT spectral pruning. The binary logical MCX count and ideal Fourier rotations are incompatible units and cannot establish efficiency gains. Every test modulus is classically factored; zero quantum benefit can be inferred. Full A29 remains open until original spectral implementation, exact gates/modular multiplication, recycled-qubit routing and recovery are integrated on matched cases with total cost accounting.
