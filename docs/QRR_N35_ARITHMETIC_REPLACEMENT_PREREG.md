That result, raw JSON and independent audit must NOT be overwritten. The identity `ord_35(2)=12`, `ord_35(8)=4` is validation-only; N35 is trivially classically factored, and this is not real hardware.

We will independently test the preexisting **arithmetic-based** controlled modular multiply from `hardware/generic_modarith_shor.py` rather than 64-state full-permutation decomposition. The algorithm uses polynomially structured n-bit reversible shift-and-mod-add, accumulator, SWAP and inverse-uncompute, controlled on public base powers, and preserves y>=N basis states. Unlike a prespecified 12-state affine orbit, it does not inject secret multiplicative order or an orbit. It is algebraically generic in n but Qiskit synthesis may be costly in practice. We will use the existing `hardware/ibm_shor35_generic_modarith_preflight_explicit.py` *explicit* compatibility lowering: comparator via Qiskit IntegerComparator with n-1 clean scratch qubits, controlled DraperQFTAdder for mod-2^n addition, eager controlled ops to avoid recursive annotated-operation HLS width mismatch.
